# Release Notes

## v1.0.0

Initial publication release of Secure Tunneling Labs.

Included experiment families:

- MACsec
- ANYsec
- IPsec
- WireGuard
- TLS
- DTLS
- SSH
- PKI
- Post-Quantum and Hybrid Mechanisms

Main artifact components:

- documentation site
- experiment workflows
- topology descriptions
- configuration files
- OpenSSL command sequences
- Wireshark packet-analysis tasks
- failure experiments

Known limitations:

- Some experiments depend on vendor images or emulator support.
- PQ experiments depend on OpenSSL version and build configuration.
- Measurements are illustrative, not a complete benchmark suite.
